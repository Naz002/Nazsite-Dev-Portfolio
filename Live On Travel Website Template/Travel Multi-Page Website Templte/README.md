# Live On - Travel Website Template

## Version 1.0.0

Live On is a responsive multi-page travel website template built with
HTML, CSS, and JavaScript. It is designed to be easy to customize and
deploy on standard static web hosting.

## Features

- Responsive design
- Multi-page travel website
- Home page
- About page
- Destinations page
- Travel packages page
- Contact page
- Responsive navigation
- Package selection from package cards
- Contact form integration
- Centralized site configuration
- Easy customization
- No database required
- No Node.js required

## Pages

- Home
- About
- Destinations
- Packages
- Contact

## Requirements

- Modern web browser
- Static web hosting
- No database required
- No Node.js required

## Quick Start

1. Download and extract the template files.
2. Open `index.html` in a web browser to preview the website.
3. Customize your website information in:
   `config/site.js`
4. Replace the demo content, images, links, and contact information
   with your own.
5. Upload the files to your web hosting.

## Customization

Most basic website information can be changed from:

`config/site.js`

You can update:

- Website name
- Tagline
- Email address
- Phone number
- WhatsApp number
- Address
- Social media links
- Copyright information

### Replacing Images

The main template images can be replaced without editing the HTML,
provided that you keep the same filename and file extension.

1. Open the `assets/images/` folder.
2. Find the image you want to replace.
3. Prepare your replacement image.
4. Rename your replacement image to exactly the same filename.
5. Replace the existing image.
6. Refresh the website.

Example:

To replace the homepage hero image:

Open:

`assets/images/homepage/hero/`

Find the hero image currently used by the homepage, then replace it with your own image using the same filename and file extension.

This allows you to replace the image without editing the HTML code.

## Contact Form

The contact form uses an external form-processing service.

Before publishing the website, configure the form endpoint in `config/site.js`.

The template does not include a database, Node.js backend, or server-side application. You will need to create and configure your own account with a compatible form-processing service.

Follow your chosen service’s instructions for any additional setup.

**Security note:** Do not place secret API keys, private credentials, or server-side secrets in front-end JavaScript. Use only public form identifiers or tokens intended for browser use. If the service requires a secret key, use its recommended secure integration method.

Do not use or share personal API keys or credentials from the template author.

After configuring the form service, submit a test message from the Contact page to confirm that the form is working correctly.

### Important

Keep the original filename and file extension when replacing an image.

For best results, use an image with a similar aspect ratio and suitable
dimensions.
